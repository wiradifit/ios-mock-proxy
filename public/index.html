📱 iOS Simulator & App Setup Guide

LocalMockAPI runs on http://localhost:8080. Follow these simple steps to route your iOS app's network calls through it without touching any system settings.

Step 1

Set Upstream Backend Target

Enter your real Staging backend URL in the top bar (e.g. https://api-staging.example.com). When an endpoint is not mocked, requests will seamlessly proxy to this staging backend.

Step 2

Update Base URL in your iOS Codebase

In your app's environment configuration (e.g. EnvironmentURL.swift or Debug Scheme settings), set your Base URL to:

http://localhost:8080

💡 Simulator Tip: The iOS Simulator runs on your Mac's localhost network. No Wi-Fi proxy or SSL certificates are needed!

Step 3

Quick Verification with Terminal / curl

You can test an endpoint right now from your terminal:

curl -i http://localhost:8080/api/v1/user/profile

You will see the mocked response returned instantly and logged in the Live Traffic tab above!

Step 4

Physical Device on Local Wi-Fi (Optional)

If testing on a physical iPhone connected to the same Wi-Fi network as your Mac, find your Mac's local IP address (e.g. 192.168.1.50) and set the app's Base URL to http://192.168.1.50:8080.
