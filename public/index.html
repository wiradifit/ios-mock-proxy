📱 Multi-Platform Setup Guide

        

          ios-mock-proxy runs on http://localhost:8080. Follow the quick setup for your platform below:
        


        
        

          
🍎 iOS

          

            
iOS (Swift / SwiftUI / UIKit / Simulator & Device)

            
Point your app's base API URL to the proxy running on your Mac's localhost:

            

              // For iOS Simulator:
static let baseURL = URL(string: "http://localhost:8080/api/")!

// For Physical iPhone (Same Wi-Fi network):
static let baseURL = URL(string: "http://192.168.1.50:8080/api/")!
            

            
💡 Info.plist (ATS Note): Allow local HTTP networking during development:

            

              <key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowsLocalNetworking</key>
    <true/>
</dict>
            

          

        


        
        

          
🤖 Android

          

            
Android (Kotlin / Java / Retrofit / OkHttp)

            
Android Emulators access your host machine's localhost via the special IP 10.0.2.2:

            

              val baseUrl = if (BuildConfig.DEBUG) {
    "http://10.0.2.2:8080/api/" // Android Emulator
} else {
    "https://api.example.com/api/"
}
            

          

        


        
        

          
💙 Cross-Platform

          

            
Flutter & React Native

            
Detect platform dynamically to use localhost on iOS and 10.0.2.2 on Android:

            

              // Flutter (Dart):
String baseUrl = Platform.isAndroid ? "http://10.0.2.2:8080/api" : "http://localhost:8080/api";

// React Native (TypeScript):
const BASE_URL = Platform.select({
  ios: 'http://localhost:8080/api',
  android: 'http://10.0.2.2:8080/api',
});
            

          

        


        
        

          
💻 Web

          

            
Web Frontends (React, Vue, Vite, Next.js, Axios)

            
Set your local environment variable or Axios baseURL:

            

              VITE_API_BASE_URL=http://localhost:8080/api
            

          

        


        
        

          
⚡ Test

          

            
Quick Verification with curl

            
Test the mock proxy right now from your terminal:

            

              curl -i http://localhost:8080/api/v2/pokemon/pikachu
            

            
You will see the mocked response returned instantly and logged in the Live Traffic tab!
